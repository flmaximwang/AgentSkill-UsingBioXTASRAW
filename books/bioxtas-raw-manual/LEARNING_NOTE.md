# 学习笔记：SAXS 数据不是"点一个按钮"出来的

> 类比开篇：**RAW 更像一台"带刻度的尺子"，而你的样品决定了尺子该放在哪。** 尺子（软件）本身不会告诉你它是不是放歪了——刻度（.cfg 里的几何）是别人（线站）替你摆好的；一旦离开了那个环境，摆尺子这件事就落到你头上。

---

## 一、这份材料在讲什么

它是一份 BioXTAS RAW 的操作手册（作者把官方英文文档翻译过来，再换用上海光源 BL19U2 的真实数据做例子）。核心链条只有一条：

**拿到的 20 张 2D 探测器图像 → 积分成曲线 → 平均成一条 → 扣掉缓冲液 → 存成 .dat → （可选）读一个 Rg。**

每一步都不难，难的是**怎么知道这一步做对了**。手册给了两类"可核对的锚点"：
- 硬数字锚点：标样一级峰在 **q = 1.076 nm⁻¹**（山嵛酸银，周期 5.8 nm）；
- 界面状态锚点：`A_` = 平均（绿）、`S_` = 扣减（红）、文件名前的 `*` = 还没保存、背景变蓝 = 已选中。

把这两类锚点用起来，整套流程才从"照着点"变成"能自查"。

## 二、三条方法论（每条一句大白话 + 一句话案例）

### 1. 配置先行：积分需要的几何信息不在图像里（skill：`configure-bioxtas-raw-for-a-dataset`）

一张 tif 里有像素，但没有"光斑在哪、样品离探测器多远"。这四件事（光斑中心、样品-探测器距离、掩膜、标度）活在 `.cfg` 里，**且不属于任何一张图像**。

所以"拿今天的数据、跑昨天的配置"是一条完全合法的操作序列——**软件不拦你**，它照样给你一条曲线，只是 q 轴和 Rg 全错。这类错误不会自首，你得自己去查：拿当天标样帧积分，看一级峰落在 1.076 nm⁻¹ 没有。

> 一句话案例：BL19U2 的做法是线站工作人员在实验前把当天参数导进 RAW；你把自己电脑上的数据拿来处理时，要自己补这一步（`File → Load Settings…`）。

### 2. 还原流水线：四段各解决一类误差（skill：`reduce-saxs-frames-to-curves`）

- **积分**（2D→1D）：把一圈一圈的像素压成一条曲线，消掉几何维度和像素涨落；
- **平均**（约 20 帧 → 1 条）：随机噪声按 √N 下降——20 帧约压到 1/4.5；**但它同时会把辐射损伤、流动不稳这类漂移一起抹平**，所以平均之后必须把单帧曲线藏起来、单独看这条平均曲线；
- **扣减缓冲液**：测到的"蛋白信号"其实是蛋白+缓冲液+毛细管；扣掉匹配的缓冲液平均曲线才得到净散射。扣减双方都应是**代表曲线**，用单帧去减会把那帧的噪声带进结果；
- **落盘**：`.dat` 是交付物；2D 图像只是"能重做"的保险。

自检靠状态机：**有了 `S_` 曲线、且 `*` 已经消失，才算做完。**

> 一句话案例：10 mg/ml BSA 的 20 张 `bsa10_0002_000xx.tif` 走完十步；列表里依次出现"蓝色选中 → 绿色 `A_` → 红色 `S_` → `*` 消失"。

### 3. Guinier 判读：自动选区只是起点（skill：`assess-guinier-fit-quality`）

Guinier 分析就是在小 q 区画一条直线，而"画得成不成立"取决于 q·Rg 足够小。三个旋钮：

- **n_min（下界）**：最低的几个 q 点最脏（Beamstop 边缘、束流杂散、少量聚集在小 q 处贡献极大）。RAW 打开窗口时会自动丢掉一些——本例 **n_min = 11**，也就是丢掉了 11 个点。丢掉没错，错在"你不知道你丢了什么"。手动调到 8 再看 Rg 变不变，就是在探测低 q 到底有多脏。
- **残差（证据）**：看形态，不看"像不像直线"。残差有系统性弯曲 → 这个区间里根本不是一条直线，Rg 是"拟合出来"的而不是"读出来"的。
- **q_max·Rg ≈ 1.3（上界）**：球状、单分散粒子的经验边界（本例 1.27）。再往上取点，是拿失效的近似换更多的点。

还有一条最容易踩的：**Rg 的单位是 1/q**。q 用 Å⁻¹ 就出 Å，q 用 nm⁻¹ 就出 nm——"Rg 差了 10 倍"十有八九是单位，不是数据。

> 一句话案例：lyz2 曲线把 n_min 从 11 调回 8、看 Rg 动不动；同时核对 q_max·Rg = 1.27 对 1.3。

## 三、批判视角：这本手册可能错了/漏了什么

1. **它把最难的一步外包了。** 原文原话是"如有其他设置问题，请联系线站工作人员"——配置（校准、掩膜）的建立不提。于是这份材料只在"你在那个线站、那个流程里"成立；换个环境，最先断的就是最关键的一环。
2. **通篇不谈数据质量。** 每个样品"约 20 帧"是描述，不是判据：要不要剔帧、怎么发现辐射损伤、流动稳不稳——一个字都没有。20 帧平均能降噪 4.5 倍，也能把一条正在坏掉的曲线"平均得很漂亮"。
3. **把经验值当定律。** `q_max·Rg ≈ 1.3` 原文写了"像 lyz 这样的球状蛋白质"，但读者极易把它记成通用规则。IDP、多聚体、聚集样品上它不成立——判据用错，比没有判据更危险。
4. **自动选区与人工判断的关系被轻轻带过。** 文章说 RAW 会自动找"最佳 Guinier 区域"，紧接着的实例就演示了它跳过了 11 个点。**"最佳"是数值意义上的，不是物理意义上的**——它不认识"低 q 被污染"和"低 q 该丢"的区别。
5. **能力清单当教程用的风险。** 结尾列了 GNOM/BIFT、Shape&Size、贝叶斯 MW、3D 重建，都只有一个外链。读了不代表会用。

## 四、适合谁读

- **正在 BL19U2（或任何 SAXS 线站）做溶液散射、要自己处理数据的人**：直接可用，尤其"配置先行"和"四段流水线"。
- **已经会做、但说不清"我凭什么相信这个 Rg"的人**：第三部分（判读）是补丁。
- **不做 SAXS 的人**：不必读细节，但有两条迁移得走——*沉默的失败需要用主动探针去发现*、*自动化的默认值是数值最优而不是物理最优*。

## 五、知识地图

```
        会话几何（.cfg）          2D 帧                1D 曲线               Rg
    configure-…  ──依赖──▶  reduce-…  ──依赖──▶  assess-…
        ▲                     │                     │
        └──── 组合（Rg 整体偏移先查配置）◀───────────┘
```

顺序天然由数据形态决定：**会话几何 → 2D 帧 → 1D 曲线 → 拟合值**。每一步都可以回查上一步，但跳不过去——没有扣减过的曲线去谈 Rg，等于拿带背景的信号做小角展开。
