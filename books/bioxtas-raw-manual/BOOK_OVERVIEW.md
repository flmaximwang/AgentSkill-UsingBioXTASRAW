## 步骤 1 — 结构（Structural）

**一句话主旨**：SAXS 数据的还原不是一个按钮，而是一条「**配置 → 积分 → 平均 → 扣减 → 保存**」的流水线；RAW 只是这条流水线的执行器，几何与掩膜全靠配置文件带进来。

**一级论点（5 个，并列中带递进）**：

| # | 论点 | 位置 | 与其他论点的关系 |
|---|---|---|---|
| 1 | RAW 是什么、能做什么 | §0 引言 | 前提 |
| 2 | 怎么装（SourceForge 预构建安装程序 / 源码编译） | §1 | 一次性前置 |
| 3 | 界面怎么组织（三面板 / 四绘图选项卡 / 顶部菜单） | §2 | 是 4、5 的操作载体 |
| 4 | 配置是必要条件（定心校准 / 掩膜 / 标样与绝对标度） | §3 | 是 5 的前提（q 轴错了 Rg 无意义） |
| 5 | 一次完整数据预处理 + 吉尼尔分析 | §4、§5 | 主体：流水线 + 判读 |

**作者试图解决的核心问题**：
> 「我在线站拿到的一批 tif，怎么变成一条能交给下游（ATSAS）的曲线，并且我怎么知道这条曲线可信？」

## 步骤 2 — 解释（Interpretive）

### 关键术语（作者本人的用法，非字典义）

| 术语 | 作者用法 |
|---|---|
| 配置文件 / cfg | 把「定心 + 校准（样品到探测器距离）+ 掩膜 + 标样」打包在一起的会话设置；**不属于图像文件**，须每次加载 |
| 积分（integrate / Plot） | 2D 探测器图像 → 1D 散射曲线的环形平均 |
| 平均（Average） | 同一条件下的一批帧合成一条曲线；产物的文件名以 `A_` 开头、显示为绿色 |
| 扣减（Subtract） | 从蛋白曲线中减去缓冲液曲线，得到净散射；产物以 `S_` 开头、显示为红色 |
| 星标（标星） | 标记「哪一条是缓冲液」，Subtract 时的角色分配方式 |
| 掩膜（Masking） | 把坏点与 Beamstop 遮掉，使其不参与积分 |
| 标样 | BL19U2 用山嵛酸银（Silver Behenate，周期 5.8 nm，第一峰 q = 1.076 nm⁻¹）作 SAXS 校准锚点 |
| 吉尼尔区域 / n_min / n_max | Guinier 直线取点的起止索引；n_min=11 表示跳过前 11 个最低 q 点 |
| q_max·Rg | 拟合区间的合理性指标；球状蛋白经验值 ≈ 1.3（文中 lyz2 实例为 1.27） |

### 核心命题（用蒸馏者的话重述）

1. 处理任何图像之前都必须加载适当的配置，否则积分出来的 q 轴与几何是错的——**而且程序不会报错**。
2. 配置内容 = 定心 + 校准 + 掩膜 +（可选）绝对标度 / 分子量标样，四件事绑在一个 .cfg 里。
3. 线站惯例：每个样品约收 20 帧；同一样品的帧可先平均再扣减。
4. 扣减的对象是「平均缓冲液」，扣减关系靠星标指定；蛋白平均 × 缓冲液平均 = 净散射。
5. 曲线的前缀与颜色是状态机：`A_` 平均 / `S_` 扣减 / `*` 未保存 / 蓝色=选中。
6. `.dat` 是 SAXS 曲线的标准交付格式；图像可丢，曲线必须落盘。
7. Guinier 拟合由 RAW 自动选区起步，但**自动选区只是一个起点**（实例中它跳过了低 q 点）。
8. 判读拟合看三处：残差图、n_min/n_max 的 Rg 稳定性、q_max·Rg 是否在 ≈1.3。
9. Rg 的单位是 1/q（q 用 Å⁻¹ → Rg 用 Å），这是数量级错误的常见来源。
10. 更高级的分析（GNOM/IFT、Shape&Size、贝叶斯 MW、3D 重建）超出本文范围，指向在线文档与 docs 文件夹。

### 论证链

文章不靠论证推进，而靠**一条可复现的演练**：以 10 mg/ml BSA 的 20 帧（`bsa10_0002_000xx.tif`）走完 §4 十步，再以 lyz2 走完 §5 的 Guinier 判读。可信度来自「步骤可复现 + 界面截图」，不是来自推理。

## 步骤 3 — 批判（Critical）★

**时代 / 工具局限**
1. 写于 2024，RAW 迭代快：菜单文字（原文把 Options 拼成 `Opitons`）、默认值、窗口布局都可能已变；截图会过期。
2. 文中的像素/探测器参数（Pilatus 2M，1679×1475 px，像素 172 µm）是 **BL19U2 当时的配置**，不是通用事实。

**立场盲点**
3. 作者是线站人员视角：把「配置由线站工作人员设好并导入」当成前提，把全流程里最难、最依赖判断的一步**外包了**（原文原话是「如有其他设置问题，请联系线站工作人员」）。离开该线站 / 自建台 / 用别人的数据集时，文章在这一点上断链。
4. 通篇没有一句关于**数据质量**的讨论：不检查帧间一致性、不提辐射损伤、不提要不要剔帧、不提样品的聚集/多分散。对「20 帧」这个惯例只有描述没有判据。

**未被证明的假设**
5. 假设 20 帧同质且无损伤（平均能降噪，也能掩盖漂移）。
6. 把 **q_max·Rg ≈ 1.3** 当通用判据（只对球状、单分散粒子成立；IDP、多聚体、聚集样品不成立）。
7. 假设 RAW 自动选出的 Guinier 区域可用——但紧接着的实例就演示了它跳过前 11 个点、需要人工下调。

**最强反对意见**
8. 这是一份「点按钮教程 + 原文翻译」：价值在把官方英文文档与线站实际操作对上号，但它不回答「我的数据可不可信」。资深 SAXS 用户会认为真正的判据（何时该怀疑数据）只给了 n_min 与 q_max·Rg 两条，其余靠经验；文末对 IFT / Shape&Size / 3D 重建只是列了能力清单，没有流程也没有判停标准。

→ 上述 3、4、5、6、7 条直接成为各 skill 的 **B（边界）** 字段与 rejected/ 的判据来源。

## 步骤 4 — 应用潜力（Applicability）

**可 skill 化**（框架 / 清单 / 判据）：
- 配置作为先决条件：加载什么、怎么确证配置没错 → skill
- 2D→1D 还原流水线（含命名/状态语义） → skill
- Guinier 拟合的选区与判读判据 → skill

**不适合 skill 化**（降级为 reference / 术语 / 案例）：
- 安装步骤（一次性、随版本变）
- 界面巡览（三面板 / 四选项卡 / 菜单）→ 作为共享 reference，不独立成 skill
- 分子量测定的多法清单（只有能力列表，无流程无判据）→ rejected
- 线站参数（山嵛酸银 5.8 nm / 1.076 nm⁻¹、Pilatus 2M 像素）→ 术语表 + 案例素材

**预估 skill 数量**：2–4；**实测 3**（见 `verified.md`：通过 3 组 / 淘汰 3 组）
**优先级**：还原流水线 > Guinier 判读 > 配置确证（配置在叙事上是前提，但它是「检查 + 加载」，动作更少）
