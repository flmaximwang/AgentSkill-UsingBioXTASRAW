## U1 — `configure-bioxtas-raw-for-a-dataset`（配置确证：加载 + 用标样核对）

- **type**: framework（前置条件型）
- **候选**: f02（配置四要素）、p2-01（配置先行）、p2-02（按实验当天对应 cfg）、p2-08（标样核对）、p4/ce01（没加载配置就积分）、p3/a03（BL19U2 的日常做法）

**V1 跨域** — 通过（按调整后的判据）。
"配置决定 q 轴与掩膜"这一事实在**两个互不依赖的操作场景**中被使用：
- §3 场景（配置本身）：定心 + 校准 + 掩膜 + 标度如何决定积分结果；
- §4 第①步场景（还原流水线首步）：用户被要求先在文件选项卡里打开目录、把 TIF 过滤好再积分——配置在此时已经生效；
- §5 场景（判读）：Rg 与 q_max·Rg 全都建立在 q 轴之上，配置错则判读全部失效。
三个场景里没有任何一个依赖另外两个的成立，因此满足"独立出现"。

**V2 预测力** — 通过。
- 新问题（文章没讨论）：*"我把线站的 tif 拷回家，用自己电脑上的 RAW 处理，q 轴数值看起来只有文献里的十分之一、Rg 也差 10 倍，是数据坏了吗？"*
- 推导出的答案：不是数据问题，而是**会话里没有当天的几何配置**——积分需要的定心与样品-探测器距离不在图像文件里，程序用的是上一次（或默认）的值，不报错。检验手段恰好是文章给的另一条线索：拿当天标样帧积分，看一级峰是否落在 1.076 nm⁻¹。这个结论文章没有明说（它只说"任何时候都要加载配置"），是本单元外推出来的。

**V3 独特性** — 通过。
常识是"处理数据要选对参数"；本单元的反直觉处在于**错误是沉默的**：RAW 不报错、曲线形状也看不出异常，唯一可靠的探针是标样峰位。"沉默的失败需要主动的探针"不是任何聪明人凭直觉就能说出来的排序。

→ 进入阶段 2。

## U2 — `reduce-saxs-frames-to-curves`（2D 帧 → 1D 曲线的还原流水线）

- **type**: framework（流程型）
- **候选**: f01（十步流水）、p2-03（先平均再扣减）、p2-04（前缀/颜色状态机）、p2-05（曲线必需品、图像保险）、p3/a01（BSA 20 帧）、p4/ce03（不隐藏单帧）、p4/ce04（不保存就清理）

**V1 跨域** — 通过。三处独立场景：
- §4 ①–⑥场景：把一批帧变成多条曲线（积分）；
- §4 ⑦⑧场景：把多条曲线收敛成代表曲线（平均 + 隐藏单帧才能检查）；
- §4 ⑨⑩场景：把两条代表曲线合成净散射并落盘（扣减 + 保存）。
每一步的产物在列表里留下**不同**的状态痕迹（蓝色选中 / 绿色 A_ / 红色 S_ / `*`），三处各自独立成立。

**V2 预测力** — 通过。
- 新问题：*"我按流程做了平均和扣减，曲线看着挺舒服，为什么下游软件说我的曲线不能用？"*
- 推导出的答案：多半是**序列里漏了落盘或漏了扣减的角色分配**——`S_` 前缀不存在说明扣减没成功（星标给错了对象），`*` 还在说明文件没有被真正写出，会话一关就没了。文章没有把"如何自查流水线走到哪一步"写成判据，本单元给出了（前缀 + 颜色 + `*`）。

**V3 独特性** — 通过。
"先平均再扣减""用前缀判断状态"这类约定是 RAW 特有的操作语义，不是通用常识；尤其"扣减的角色由**星标**而不是由文件名决定"这一点，任何没读过手册的人都猜不到。

→ 进入阶段 2。

## U3 — `assess-guinier-fit-quality`（Guinier 拟合的取点与判读）

- **type**: framework（判据型）
- **候选**: f03（三旋钮）、p2-06（Rg 单位 = 1/q）、p2-07（q_max·Rg ≈ 1.3）、p3/a02（lyz2 的 n_min 11→8）、p4/ce02（盲信自动选区）

**V1 跨域** — 通过。两个独立场景 + 一个跨步依赖：
- §5 ③场景（取点下界）：n_min 跳过低 q 点，调整后 Rg 是否变化；
- §5 ④场景（取点上界）：q_max·Rg ≈ 1.3 决定 n_max 停在哪，同时要看残差；
- §5 ②场景（单位）：Rg 的单位随 q 变，是独立于取点的另一类错误来源。
三者互不依赖：可以取点完全正确而单位写错，也可以单位对而取点错。

**V2 预测力** — 通过。
- 新问题：*"我这条曲线的 Rg 在 n_min=5 时是 3.2 nm，n_min=11 时是 2.4 nm，文献里这个蛋白是 2.3 nm，所以我该报 2.4 吗？"*
- 推导出的答案：不能只按"哪个更接近文献"选。取点下移把更多低 q 点纳入，若低 q 被聚合/束流杂散污染，Rg 会被系统性抬高；正确做法是看残差形态 + 检查 Rg 对区间的稳定性，并把"区间不稳定（>10–20%）"本身作为"这条曲线不适合给单一 Rg"的结论。文章只演示了"调一调、看变化"，没有给出这条判停规则。

**V3 独特性** — 通过。
"自动选区只是起点""残差比 R² 更能说明问题""Rg 必须连区间一起报"三条，都是外行直觉的反面（直觉是"软件的默认值就是推荐值"）。

→ 进入阶段 2。
