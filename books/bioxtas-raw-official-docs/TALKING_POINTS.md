# 话术库 — 拿 BioXTAS RAW 这套判据去和别人说

> 规则：每条都是**你能自然说出口**的话（不是文档金句），≤100 字，带场景标签。
> 用途：组会讲自己的数据、回复合作者、给师弟师妹解释、写方法学段落。

1. **[解释为什么曲线不能用]** 「这条曲线的 q 轴我核过标样峰位，是对的；但 Guinier 残差是 smile，说明有聚集，Dmax 和重建都不能信——先把样品过一遍 SEC 或高速离心重收。」

2. **[别人问 Rg 准不准]** 「Rg 我可以报，但得带上 q 区间、n_min/n_max 和 q_max·Rg。只给一个数是不可比的：同样一条曲线，取点不同 Rg 能差 10–20%。」

3. **[被问"我的 Rg 在 2.3–2.5 nm 之间跳正常吗"]** 「先看是不是区间不稳。如果确实是取点已经覆盖到 q_min·Rg<0.65、上界在 qRg≈1.3 以内还在跳，那这条曲线不该给单一 Rg——该去做 P(r)。」

4. **[有人想用 SAXS 定分子量]** 「SAXS 的 MW 一般只有 ~10% 精度，用它判低聚态可以，报分子量不合适。要准确值得上 SEC-MALS，最好的做法是同一针洗脱上同时测 SAXS 和 MALS。」

5. **[SEC 数据要报 MW]** 「SEC 里浓度未知，所以绝对刻度和标样比对这两类都不能用。走 Vc 或 Vp，装 ATSAS 的话 Bayesian 最稳（中位偏差 4%）。」

6. **[解释重建结果]** 「DAMMIF 的输出不是那个最漂亮的模型，是一组模型加一组指标：a-score、平均 NSD、被剔了几个、有几个聚类、χ² 是不是接近 1。这些不过关，形状就不能写进文章。」

7. **[别人拿一个形状来问"像不像"]** 「SAXS 数据的强项是证伪，不是生成形状。同一个曲线能对应好几个形状，所以要么跑 15 个重建做平均，要么用高分辨模型算理论曲线直接拟合数据来比。」

8. **[被问 Dmax 怎么定]** 「别直接取默认值。把 Dmax 设成初值的 2–3 倍，先关掉 force-to-zero，看 P(r) 自然落到零的位置，再微调、再把约束打开。精度不可能优于 5%，别在最后一位上纠结。」

9. **[P(r) 该不该截断]** 「看下游是谁：给 DAMMIF/N 就截断到 8/Rg 或 0.25–0.30 1/Å 取小者；给 DENSS 千万别截断。两个分支用反了，一个是必要处理，一个是自毁。」

10. **[绝对刻度常数算错了]** 「先别怀疑数据。查两件事：算常数前有没有把绝对刻度关掉；算完之后有没有又改过归一化（含通量/透射）。这两条都会给出坏常数，改完要重算。」

11. **[掩膜画了但没生效]** 「掩膜有两套保存：Save to File 只是存 .msk 文件，要生效得按 Set，它才随设置保存。Clear 之后也一样得重新 Set。」

12. **[峰重叠想分解]** 「先用 SVD 数有几个组分，别信自动判的分量数。标准 SEC 用 EFA，IEC 或滴定这种不按顺序出的用 REGALS。任何分解结果都要用别的证据佐证，它只给可能性。」

13. **[要做批量/可复现分析]** 「GUI 点 30 次不如写脚本。RAW 有 Python API：先 load_settings 载入配置，再 load_profiles 循环 auto_guinier，最后 save_report 出报告——GUI 能对 series 做的 API 都能做。」

14. **[时间分辨数据]** 「时间轴不是自动的，要用流量校准换算（x→time 加 offset）；然后裁 q（低 q 有寄生散射、最高 q 一半是负值没信号）、排除首帧、再 rebin 降噪。首帧的 Rg 报 0 就是不正常。」

15. **[说服自己/别人"判据优先于直觉"]** 「凡是看起来像柔性的，先排除缓冲液扣减不准；凡是看起来像聚集的，先看残差形态。文档里最有用的一句是：**高质量数据不保证好重建**——每一步都要证伪一次。」
