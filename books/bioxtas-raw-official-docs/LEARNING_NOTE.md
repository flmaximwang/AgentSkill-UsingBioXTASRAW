# 学习笔记 — 把 BioXTAS RAW 官方文档读完，我真正学到的是什么

> 类比开篇：**这份文档不像教程，像一份"仪器在什么时候是可信的"检查表。**
> 它很少教你点哪个按钮，几乎每一节都在回答同一个问题：*你手上这个结果，凭什么算数？*
> 于是读完的收获不是"会用 RAW"，而是**手上多了一把尺子**——知道每一步的误差是从哪里进来的，以及怎么用最小的代价把它证伪。

---

## 一、整条流水线其实是一条"判据链"

RAW 的流程看着很长（图像 → 曲线 → Rg → P(r) → MW → 形状 → 模型对照），但每一段都只做一件事：**把上一段里最大的那个误差源干掉，并且留下证据说它真的被干掉了。**

- 原始 2D 帧 → 积分：干掉方位角；留下 q 轴（**这一步的正确性完全由配置决定**）。
- 多条曲线 → 平均：干掉统计噪声；留下"这些帧彼此像不像"的证据（残差/比率/CorMap）。
- 平均样品 − 平均缓冲液：干掉溶剂背景；留下 `S_` 前缀与干净的残差。
- Guinier：从小 q 抽 Rg/I(0)；留下的证据是**残差形态**，不是 R²。
- IFT：把 I(q) 反演成 P(r)；留下的是 Dmax 与 χ²。
- MW / 形状：由前面的量推；留下的是**方法之间是否收敛**与一组评估指标。

一句话：**每一步的真正产出不是数字，是"这个数字凭什么信"的记录。**

## 二、七个我原来会做错的地方

1. **配置错是静默的。** 没加载当天的 `.cfg`，RAW 不报错、曲线照画，但 q 轴与 Rg 全错。→ 探针：拿当天标样积分，看一级峰是否落在该在的位置。
2. **掩膜有两套保存语义。** `Save to File` 只写磁盘 `.msk`，进内存必须按 `Set`（`Clear` 之后同样要 Set）。→ 症状：beamstop 阴影还在曲线里。
3. **Guinier 的上界与下界都是数字。** `q_min·Rg < 0.65`（球/盘可放到 1.0）；上界按形状分档——棒 ~1.0、球 ~1.3、盘 ~1.7（取 1.3/1.0 是为了让偏离近似带来的误差 <10%）。残差呈 **smile 是聚集、frown 是排斥**，而坏缓冲液扣减会同时装成这两种样子。
4. **Dmax 是可以"看出来"的。** 低估 → P(r) 被逼着陡降到零；高估 → 到零后绕零振荡。正确动作是先把 Dmax 放到初值的 2–3 倍、**关掉 force-to-zero** 让它自然落零，再微调、再重开约束。它有硬底：**精度不优于 5%，有时接近 10%**。
5. **P(r) 的截断规则是"分叉"的。** 喂 DAMMIF/N 要截断到 `max q = 8/Rg` 或 `0.25–0.30 1/Å`（取小者）；喂 DENSS **不要截断**。同一份 P(r) 用错分支，一边是必要处理，另一边是自毁。
6. **分子量不该由 SAXS 定。** 通则 ~10% 不确定度；它的用处是判低聚态，不是报分子量（要准确值用 MALS/AUC，最好 SEC-MALS-SAXS）。而且选法不是"选最准的"，而是**先看哪一类能用**：池中浓度已知→绝对刻度/标样；SEC 洗脱（浓度未知）→ 只能 Vc / Vp / Shape&Size / Bayesian。
7. **形状重建的输出不是一个形状。** 是**一份带评估指标的模型集**：a-score 判歧义、平均 NSD 判稳定性、被剔模型数、聚类数、χ²、模型 Rg/Dmax 要回得来对得上 P(r)、由体积推的 MW 差 >20–25% 就说明可疑。文档的原话更狠：*"高质量数据不保证好重建"*——SAXS 擅长证伪，不擅长生成。

## 三、三个"顺序"是有代价的

1. **绝对刻度的顺序**：算常数之前必须**关掉**绝对刻度（否则得到坏常数）；常数算完之后**不得再改归一化**（含通量/透射），改了就得重算。这是本卷里最反直觉的一条。
2. **先证伪，再下结论**：看到 Kratky 上翘先怀疑缓冲液扣减，看到低 q 上扬先怀疑聚集（**<1% 的聚集就足以污染 Dmax 与三维重建**），看到 Dmax 找不到先怀疑粒子间排斥。
3. **去卷积的调参是分层的**：分量数（先用 SVD 独立核对）→ 区间（Forward/Backward EFA 起点）→ 正则化 λ（按数量级调）。改任一层 RAW 都不会自动重算；最后一轮必须关掉 "Start with previous results"，否则结果是路径依赖、不可复现。

## 四、批判视角：这份文档本身哪里不能信

1. **手册层整体过时。** `20-manual` 全部 19 节顶部都写着"落后好几个版本，请以 tutorial 为准"，而且与教程有 8 处硬冲突（Python 版本、MW 方法数、绝对校准标准、ATSAS 清单、特性表、窗口清单、`.sec` vs `.hdf5`、平台支持）。→ 我的做法：把手册当"历史对照"，任何结论都以 tutorial / api / saxs 为准。
2. **API 参考是空壳。** `main_api` / `profiles_and_ifts` / `series` / `settings` 四个 rst **只有标题、零正文**；函数签名只存在于 examples 里。→ 任何基于 API 的自动化，签名都要自己实测确认，不能声称"有官方参考"。
3. **文档之间存在循环引用。** 方法学章节把操作外包给 tutorial，tutorial 又写"细节见 manual"，而 manual 自己承认过时。→ 遇到这种指针，只能回到"哪个程序实际怎么算"（读源码或跑一遍）来定。
4. **CorMap 只有阈值级描述**，没有算法与阈值推导。→ 它给的是"经验可用"，不是"理论上该是多少"。

## 五、这份材料对我的研究意味着什么

- 我做的是蛋白质从头设计，SAXS 的典型用法是**"用实验曲线证伪/支持一个设计模型"**——正好落在文档反复强调的那半边能力上（证伪）。因此 `evaluate-a-shape-reconstruction` 与 `fit-a-high-resolution-model-to-data` 这两个 skill 对我比"怎么算出 Rg"更重要。
- 判据化的好处是**把"我觉得这条曲线还行"变成可复核的清单**：写给合作者或审稿人时，可以直接引用阈值（qRg 上下界、NSD、a-score、χ²、Dmax 5%、体积 MW 20–25%）。
- 最容易被忽略的一条，也是最贵的一条：**配置与顺序错误都是静默的**。所以每次开始处理数据前，值得花两分钟做那两个探针（标样峰位、常数对基准值）。
