# 学习笔记：SEC-SAXS 里，"一条曲线"的边界得你自己划

> 类比开篇：批次实验像**从一桶水里舀一杯**——杯子的边界是现成的（那 20 张 tif）。SEC 像**看一条河从你面前流过**：河里何时清、何时浊、何时漂着树叶，都得你盯着那段水流判断。RAW 给你的不是答案，是一张"水情图"（色谱图）和一套量尺（Rg/MW 随帧号）。

---

## 一、这份材料在讲什么

BL19U2 开了 SEC-SAXS 模式，做法上多了一步前置动作：**样品先过一根体积排阻柱，洗脱液连续流过 SAXS 样品池**，于是你拿到的不是"20 帧"，而是"上千帧 + 一根时间轴"。

处理流程因此多出一段判断：

**读色谱图（强度 vs 帧号）→ 定出缓冲液区（哪段是纯缓冲液）→ `Set buffer` 得到逐帧 Rg/MW → 用"平台"判定峰中心哪一段是单一物种 → 只把那段平均、扣减、变成一条曲线。**

关键差别一句话：**批次实验里"一条曲线"的边界来自文件；SEC 里那条边界来自你的判断，而判断需要证据——那段 Rg/MW 的平台。**

## 二、三条方法论（大白话 + 一句话案例）

### 1. SEC 系列 → 一条曲线：先看过程，再定"一个样品"（skill：`process-sec-saxs-series`）

三件不能搞错的事：

- **载入方式**：`Plot Series`，不是 `Plot`——只有 Series 才带帧号这根轴。
- **端点帧例外**：首帧常因 shutter 未及时开启整帧偏弱；**BL19U2 上末帧不参与强度校正**。它们都落在基线区里，会直接改变基线取值，先剔。
- **先平均、后扣减**：缓冲液区所有帧先平均成一条，样品区按滑窗（window=5 → 帧 0-4、1-5、2-6…）平均后再相减。反过来做（先逐帧扣再平均）会让各帧误差相关化，平均不再降噪——用 `S_` 曲线去做 Average 就是这个错。

**缓冲液区是全流程的支点**，而它有两个陷阱：Auto 只认"低而平"，主峰旁那道大而平的前肩（常常是没分开的高阶寡聚体）最容易被误选；把峰前小峰算进缓冲液区，等于把寡聚体当背景扣掉，会制造出漂亮的"假单分散"。核对办法：放大到基线逐帧看，必要时对照 SEC 的 **UV 痕**。

**判据只有一条但很硬**：峰中心应有一段 Rg 与 MW 平稳的区间。峰两侧的起伏各有名字——低信噪比、肩峰、左右基线不等。

> 一句话案例：`sec_sample_1`（965 帧）走完整轮，官方落在 sample 699–713；同一数据集微信那篇写 690–719——**两个数字不一样**，正说明区间选择有主观余量，必须自己看平台。

**还有一条硬限制（微信那篇没写）**：SEC 峰内浓度随时间变化且未知，所以**不能用标样 I(0) 比对或绝对校准定浓度**；MW 只能走 Vc（相关体积）与 Vp（校正 Porod 体积），两法结果不一致是正常的，要并列报。BSA 这个数据集给了可对照的锚点：**Rg ≈ 28 Å、MW ≈ 66 kDa**。

### 2. 基线校正：按漂移的"性质"选方法（skill：`correct-sec-saxs-baseline`）

扣减缓冲液去掉的是"溶剂的散射"，不是"基线随时间的变化"。扣完还漂，先判性质：

- **仪器/束流漂移**（束流位置/强度缓慢变化）→ 基线近似**线性**上下移，各 q 差不多 → 用 **Linear**：在峰前、峰后各取一段平的基线，连直线减掉。
- **毛细管污垢**（窗口被逐步污染，尤其受损蛋白粘附）→ 基线**随时间单调上升**且**各 q 幅度不同** → 用 **Integral**：只允许基线不降，每个 q 各算一条。

两条推论比方法本身更重要：

- **积分校正会过校正**（它只允许往上抬，本该向下的校正没发生）。诊断办法是把强度显示切成 q 区间逐段试（0.01-0.02 / 0.05-0.06 / 0.1-0.2 / 0.2-0.27 Å⁻¹），**过校正通常露在高 q**——那说明该 q 段已是噪声主导，正确处置是**先把曲线截断到低 q 再校正**，而不是硬调参考区。
- **校正与分解互斥**：做 EFA/SVD 分解时不要叠加基线校正（积分法尤其），分解算法会把校正引入的单调变形当成一个组分。要做分解，就改走"峰前 + 峰后各取一段缓冲液"这条路线。

> 一句话案例：`xylanase` 的恒定上漂 → Linear 校正后基本消失（弹"前后两段斜率不一致"的警告属常见，可继续）；`baseline.hdf5` 的污垢型漂移 → Integral 校正过头，过校正落在高 q。

### 3.（衔接第一条）判读：读 Rg 的规矩不变（skill：`assess-guinier-fit-quality`）

SEC 得到的曲线仍然要按 Guinier 的规矩读：报 Rg 必须带 q 区间、n_min/n_max、q_max·Rg 与单位（Rg 单位 = 1/q）。唯一的 SEC 特有差异是 I0 不能做绝对标度（原因同上：浓度未知）。

## 三、批判视角：这两份材料可能漏了什么

1. **微信那篇砍掉了整节基线校正。** 这是 SEC 最常见的系统误差来源之一，而文章一字未提——本包的第二个 skill 直接来自官方教程，就是因为这个缺口。
2. **它也砍掉了"浓度未知 ⇒ 不能用绝对校准/I0 标样"这条限制。** 读者很容易把批次实验的习惯搬到 SEC，得到"看起来精确但没意义"的浓度或分子量。
3. **区间质量警告没有写进去。** 官方教程里 RAW 会对选中的缓冲液区做四项检查（全 q 范围帧间相似度、低/高 q 各自行为、强度相关性、是否出现多个奇异值），对样品区还检查 Rg/MW 相关性。文章只说"满意后点 To Profiles Plot"，读者不知道软件其实会拦住你。
4. **两源都不给"该不该相信这次分离"的上位判据**：柱子分得开吗？缓冲液匹配吗？平台判据只保证"在你给的水流里，这一段是自洽的"。
5. **对帧的取舍没有系统规则**：只有两个端点例外，没有"如何发现辐照损伤帧/坏帧"的方法。这一点在 SEC 里比批次实验更要紧（一柱样品连续照 1000 帧）。
6. **强依赖线站/软件假设**：RAW 的"自动载入 series"只在 cfg 为 BioCAT / MacCHESS 时可用；BL19U2 得手选文件或用 `.hdf5`。

## 四、适合谁读

- **在 BL19U2 做了 SEC-SAXS、要自己出结果的人**：三段流程 + 两个陷阱（Auto buffer、峰前小峰）+ 一条硬限制（不能用 I0 标样），直接可用。
- **已经会跑但说不清"为什么取这段"的人**：平台判据（第三节第 1 条）是补丁。
- **不做 SAXS 的人**：可带走两条迁移——*自动化的默认值是数值最优、不是物理最优*；*当"边界"从文件变成判断时，判断必须自带证据*。
