## U4 — `process-sec-saxs-series`（SEC 系列 → 一条可信曲线的判定流程）

- **type**: framework（判定流程型）
- **候选**: q1-f01（三段式流程）、q1-f02（两类区间互牵）、q1-f03（滑窗逐帧参数）、q2-01（Plot Series）、q2-02（端点帧例外）、q2-03（自动必复核）、q2-04（先平均后扣减）、q2-05（平台判据）、q2-06（浓度未知限制）、q2-07（MW 两法并列）、q2-10（峰前小峰=寡聚体）、q2-11（区间体检）、q3-a01（965 帧演练）、q3-a02（BSA 检验点）、q4-ce01/ce02/ce03/ce05/ce07、q5-g01–g06、g09、g10、g12

**V1 跨域** — 通过（同一教程内**三个互不依赖的操作语境**）：
- **语境 1（主流程）**：`sec_sample_1` 的 1–22 步——完整走一遍"色谱图 → buffer 区 → Subtract → Rg/MW 平台 → 送 Profiles"；
- **语境 2（另一数据集的验证跑）**：BSA 的 39–45 步——同一套判断换一个样品再来一次，并给出可对照的期望值（Rg ~28 Å / MW ~66 kDa）；
- **语境 3（反向对照）**：源 A ⑫–⑮ 的手动路径——它**放弃**了逐帧参数曲线，于是恰好反证了"平台判据需要整条曲线上的信息"，而不是流程装饰。
三处各自独立成立，且第 3 处是从"不做会失去什么"这一侧给出的独立证据。

**V2 预测力** — 通过。
- 新问题（材料里没有）：*"我的峰上 Rg 平台挺平，但 MW(Vc)=45 kDa、MW(Vp)=70 kDa，我该报哪个？"*
- 推导出的答案：**不能二选一**。两法分道意味着"形状偏离球状 / 基线残留 / 信噪比不足"至少有一项成立，而这三项恰好都可用本单元的其他判据定位：先看平台是否真的平（若 Vc 平而 Vp 不平稳，多半是基线残留），再看 Unsubtracted / Baseline Corrected 两档图有无漂移，最后才决定降级报告（并列两个方法名 + 说明差异来源）。材料里只写了"可以切换显示 Vc/Vp 的 MW"，没有给这个处置规则——它是外推出来的。

**V3 独特性** — 通过。
"先看整个洗脱过程、再决定哪一段算一个样品"与"单分散的判据是参数平台而不是峰形"两条都是反直觉的（批次实验的直觉是"选一批帧、平均、扣减完事"），且不属于任何领域通识。

→ 进入阶段 2。

## U5 — `correct-sec-saxs-baseline`（扣减之后还有漂移：按性质选校正）

- **type**: framework（决策型）
- **候选**: q1-f04（两分支决策）、q2-08（双侧缓冲液 or 基线校正）、q2-09（选型规则与互斥）、q3-a03（xylanase/线性）、q3-a04（baseline.hdf5/积分/过校正）、q4-ce03（单侧缓冲液）、q4-ce06（与 EFA 互斥）、q5-g07（术语）

**V1 跨域** — 通过（同一教程内的**两个独立数据集 + 一条独立替代路**）：
- 语境 1：`xylanase` 的线性校正（源 C 1–11，漂移性质 = 仪器）；
- 语境 2：`baseline.hdf5` 的积分校正（源 C 积分节 1–11，漂移性质 = 毛细管污垢，且出现高 q 过校正）；
- 语境 3：源 B 23–33 的**双缓冲液区**路线——它不是基线校正，却是同一问题的另一条独立解，且材料明确给了二者的取舍（"若要做 EFA 就不要用基线校正"）。
三处的物理机制不同（束流漂移 / 污垢累积 / 缓冲区不等价），因此不是同一例子的复述。

**V2 预测力** — 通过。
- 新问题：*"扣减完峰后基线整体抬了 3%，能不能只对低 q 做线性校正？"*
- 推导出的答案：**不能**。基线校正对**每个 q 各施加一条**校正，只改低 q 等于人为制造一个 q 方向上的折点（kink），会让 Guinier 区与高 q 段来自两套假设。正确顺序是：先判漂移性质（随剂量累积 → 积分），再看是哪些 q 被过校正（把强度显示切成 q 区间逐段试，官方示例定位到高 q），若确认高 q 是噪声主导就**先把曲线截断到低 q 再校正**。材料给的是"两种方法 + 一个过校正现象"，这条处置顺序是把它们串起来外推的。

**V3 独特性** — 通过。
"基线漂移要按性质分两支校正""积分校正只允许基线不降、因此会在高 q 过校正""积分校正与 EFA 分解互斥"——三条都是领域内才有的判断，抹掉出处后普通聪明人说不出来。

→ 进入阶段 2。
