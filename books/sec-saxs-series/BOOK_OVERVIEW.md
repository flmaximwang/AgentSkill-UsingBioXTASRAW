## 步骤 1 — 结构（Structural）

**一句话主旨**：SEC-SAXS 不是"把一批帧平均成一条曲线"，而是**先读洗脱过程（色谱图）→ 用 Rg/MW 的平台区判定哪一段是单一物种 → 只把那一段变成曲线**；缓冲液区怎么定，决定这条曲线可不可信。

**一级论点（5 个，递进）**

| # | 论点 | 位置 | 关系 |
|---|---|---|---|
| 1 | 数据形态不同：连续采集的 series（示例 965 帧），不是"一个样品约 20 帧" | 源A ①②；源B 1–3 | 前提（决定后面所有动作与批次还原不同） |
| 2 | 色谱图是可读的：积分强度 / 平均强度 / 指定 q 或 q 区间的强度 vs 帧号 | 源A ④；源B 8 | 观察层 |
| 3 | 缓冲液区是一切的支点：自动选择会错（峰前平肩被当基线） | 源A ⑦⑧；源B 12–14 | 关键判断 |
| 4 | 判据是"平台"：峰中心 Rg/MW 平稳 → 单分散；两侧散布来自低信噪比、肩峰、基线不匹配 | 源A ⑥⑩①；源B 16–19 | 判读层 |
| 5 | 基线漂移是 SEC 特有误差源，需单独校正（线性 vs 积分） | 源C 全篇 | 兜底层（源 A 完全没写） |

**核心问题**：
> 「我这个 SEC 峰里到底是不是一样东西？这段数据能不能当成'一个样品的一条曲线'？」

## 步骤 2 — 解释（Interpretive）

**关键术语（作者/官方用法）**

| 术语 | 用法 |
|---|---|
| Series（系列） | RAW 对"按时间顺序采样的一整串数据"的叫法；SEC 只是其中一类 |
| 色谱图 / 散点图（chromatograph / scattergram） | 积分强度 vs 帧号；与 SEC 的 UV 吸收曲线形状可比 |
| buffer 区 / sample 区 | 帧号区间，不是"文件"；两者都要显式选出 |
| 滑窗平均（window size） | 逐帧计算参数时用的大小 N 的滑动窗口（N=5 → 帧 0-4、1-5、2-6…） |
| Set buffer / To Profiles Plot | 两个动作：定义缓冲液并逐帧扣减；把选定区间的平均值送到 Profiles |
| Unsubtracted / Subtracted 图 | 扣减前/后的强度-帧号图；基线校正会再加一档 Baseline Corrected |
| Calc markers | 画在右 Y 轴的 Rg / I(0) / MW(Vc) / MW(Vp) |
| Baseline correction: Linear / Integral | 线性=仪器/束流漂移；积分=毛细管污垢（每个 q 各一条校正线） |
| CHROMIXS | ATSAS 里的同类工具；默认显示 0.01–0.08 Å⁻¹ 的**平均**强度（RAW 显示该区间的**和**，所以数值不同） |

**核心命题（10 条）**

1. 载入 series 用 **Plot Series**，不是 Plot；RAW 会自动切到 Series 面板。
2. 首帧强度可能异常低（shutter 未及时开启）；BL19U2 上**最后一帧不能用于强度校正**（统计规则）→ 端点帧要剔。
3. 色谱图的纵轴可以换成平均强度或某个 q / q 区间的强度，看 SH 区总是比看总强度更能分辨小组分。
4. 缓冲液区可以自动选，**但自动一定会错几次**：主峰旁大而平的前缘肩部最容易被误选。
5. 缓冲液区必须真的是缓冲液：若 SAXS 数据本身噪声大，去对照 SEC 的 **UV 痕**找次要洗脱组分，把它们排除。
6. Set buffer 之后是"先平均、后扣减"：缓冲液区内所有帧先平均，再用滑窗逐帧平均样品并扣减（避免先扣后平均带来的相关噪声）。
7. 逐帧输出的是 Rg / I(0) / MW(Vc) / MW(Vp)；**MW 的两种估计方法结果会不一致**，这是正常现象，要一起看。
8. 判据是平台：峰中心应有一段 Rg 与 MW 平的区域；边缘的变化来自低信噪比、肩峰、左右基线不等。
9. SEC 数据**不能用 I(0) 标样比对/绝对校准来定浓度**（洗脱峰浓度未知）——MW 只能走 Vc/Vp 这类体积法。
10. 基线漂移有两种性质，对应两种校正；做了积分基线校正后**不要再用 EFA 分解**（会互相污染）。

**论证链**：两源都用可复现演练推进（源 B 用 `sec_sample_1`（965 帧）、`sec_sample_2`（BSA）；源 A 给出 BL19U2 视角的缓冲液 539–568 / 样品 690–719）。可信度来自"步骤可复现 + 每步的检查点与警告"，而非推理。

## 步骤 3 — 批判（Critical）★

**源 A（文章）相对官方教程的实质缺失**（这是本包存在的理由）

1. **整节砍掉了基线校正**（源 C）：而基线漂移是 SEC-SAXS 最常见的系统误差来源（束流漂移、毛细管污垢），文章一字未提。
2. **删掉了"浓度未知 ⇒ I0 标样/绝对校准不准"这条限制**：读者很容易把批次还原的习惯（用标样定 I0/浓度）搬到 SEC 上。
3. **删掉了区间质量检查与警告窗口**（源 B 第 20–21 步：RAW 会对 buffer 区检查帧间相似度、低/高 q 行为、强度相关性、是否出现多个奇异值；对 sample 区还检查 Rg/MW 相关性）。文章只说"满意后点 To Profiles Plot"，读者不知道软件其实会拦你。
4. **删掉了"峰两侧各取一段缓冲液"这条实用解法**（源 B 第 23–33 步）与多序列 / SVD / EFA / REGALS / 导出 CSV / 保存 report 等下游动作。
5. 保留了官方最重要的两句警告（自动 buffer 会错、峰前小峰可能是寡聚体）——这两处是文章的加分项。

**两源共同的局限**

6. **不给"该不该相信这次分离"的上位判据**：平台判据只解决"这一段是不是一个物种"，不解决"柱子分得开吗、缓冲液匹配吗"。
7. **对帧的取舍没有系统规则**：只有零散例外（首帧强度低、BL19U2 末帧不可用），没有"怎么发现坏帧/辐照损伤帧"的方法。
8. **强依赖线站/软件假设**：自动加载 series 只在 BioCAT / MacCHESS 的 cfg 下可用（RAW 靠文件名规则认系列）；BL19U2 得手选或用 HDF5。

**最强反对意见**

9. 单看文章，读者会把"SEC-SAXS 处理"记成"LC Analysis → Auto → To Profiles Plot"三步；而真正决定结果的三件事（缓冲液区是否真是缓冲液、平台区在哪、基线漂到什么程度）几乎都在被省略的章节里。这也是本次升级**必须同时收官方教程**的原因。

→ 上述 1、2、3、6、7 条进入两个新 skill 的 **B（边界）** 段与 `rejected/` 的判据。
