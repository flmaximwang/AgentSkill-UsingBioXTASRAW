# BioXTAS RAW 术语表（作者用法，不是字典义）

源：《BioXTAS RAW程序使用说明》· 刘广峰（公众号「生物小角」）· 2024-04-26
由 cangjie-skill（book2skill）的术语提取器产出（候选 `p5/g01–g12`），**不独立成 skill**，是三个 skill 的共享词典。
每条三栏：**作者定义** / **与常识的差别** / **为什么下游 skill 需要这个澄清**。

---

## g01 配置文件（.cfg）

- **作者定义**：「配置文件允许RAW将2D图像积分为1D散射曲线。」内含定心、校准、掩膜、标度。
- **≠** 数据文件的一部分，**≠** 每个数据集自带；**=** 会话级设置，与"实验当天/那台仪器"绑定。
- **为什么重要**：所有"为什么会静默出错"的答案都在这个区分里——配置不在图像里，所以打开图像不会提示配置不匹配。

## g02 定心 / 校准（centering / calibration）

- **作者定义**：「首先需要对散射图像进行定心和校准，即确定光斑中心即样品到探测器的距离」。
- **=** 两个几何量共同决定 q 轴；**≠** 软件安装参数或探测器出厂参数。
- **为什么重要**：q 轴、Rg、q_max·Rg 判据全部建立在这两个量上；它们错了，下游判据一律无意义。

## g03 掩膜（Masking）

- **作者定义**：「对探测器的坏点及Beamstop进行遮盖（Masking），让这些点不参与数据积分过程」。
- **=** 把像素标记为"不参与平均"；**≠** 背景扣减（那是 Subtract 干的事），也**≠** 把像素从图像里抹掉。
- **为什么重要**："扣背景"与"遮像素"常在口语里混为一谈，但在流水线上是不同步骤，一个在配置里做、一个在 Profiles 列表里做。

## g04 积分（Integrate / Plot）

- **作者定义**：「单击绘图按钮以对所有图像进行积分并在 Profiles 图中绘制积分散射曲线图。」
- **=** 2D 图像 → 1D 曲线的环形（方位角）平均，方向是降维；**≠** 数学意义上的"求积分面积"，也**≠** Guinier 拟合。
- **为什么重要**：用户说"积分"时可能指两件完全不同的事，先确认是 2D→1D 还是从曲线上读 Rg。

## g05 平均（Average）/ `A_` 前缀

- **作者定义**：「文件名将以绿色显示，并以 A_ 开头，表示它是平均散射曲线。」
- **=** 把 N 条同类曲线合成一条（随机噪声按 √N 下降）；**≠** 逐帧筛选后再平均——**作者没有讨论要不要剔帧**。
- **为什么重要**：平均既降噪也掩盖（辐射损伤、流动不稳会被平掉）。这条区分是 `reduce-saxs-frames-to-curves` 的边界关键。

## g06 扣减（Subtract）/ `S_` 前缀

- **作者定义**：「从测量的蛋白质散射（实际上是蛋白质的散射加上缓冲液的散射）中减去缓冲液散射曲线」；产物「名称为红色，并带有 S_ 前缀」。
- **=** 减去匹配缓冲液的散射，且扣减双方都应是平均曲线；**≠** 减去"上次实验的缓冲液"或某个通用背景。
- **为什么重要**：Subtract 的输入靠"星标 + 选中"两个 UI 动作完成；角色搞反会得到符号相反的曲线而**不报错**。

## g07 星标（marking）与选中（selection）

- **作者定义**：「背景应变为蓝色，表明它已被选中」；「给平均的缓冲液文件标星，并选择平均的蛋白质散射文件」。
- **=** 星标表示"我是背景"，蓝色选中表示"我是被操作对象"；**≠** 两者可混用。
- **为什么重要**：Subtract 的角色分配完全由这两个 UI 状态决定，是"操作错但无报错"的高发点。

## g08 标样 / 山嵛酸银（Silver Behenate）

- **作者定义**：「BL19U2使用山嵛酸银（Silver Behenate，二十二酸银盐）作为SAXS标样，该样品具有5.8 nm的周期结构，第一个峰的q值为1.076 nm-1。」
- **=** 用于核对**几何校准**的"刻度尺"（一级峰 q = 1.076 nm⁻¹）；**≠** 用于绝对强度标度的标样（水/玻璃碳那一类作用）。
- **为什么重要**：这是把"配置是否正确"转成可检验事实的唯一手段；峰位数字必须记准。

## g09 q、q_max·Rg

- **作者定义**：「Rg 值的单位为 1/q（例如，如果 q 的单位为 Å-1，则Rg 的单位为 Å）」；「对于像 lyz 这样的球状蛋白质，q_max*Rg 通常约为 1.3」。
- **=** q 是散射矢量模长（Å⁻¹ 或 nm⁻¹），q_max·Rg 是无量纲的适用范围指标；**≠** Rg 有"默认单位"。
- **为什么重要**："我的 Rg 差 10 倍"通常是单位换算（q 用 Å⁻¹ 还是 nm⁻¹），不是数据问题。

## g10 n_min / n_max 与残差

- **作者定义**：「n_min 为 11。这意味着 RAW 跳过了 Guinier 拟合的前几个低 q 点」；「底部图显示了拟合的残差」。
- **=** n_min/n_max 是 Guinier 直线的取点起止索引（与"丢弃低 q 点"等价）；**≠** 数据质量指标——残差形态才是。
- **为什么重要**：只报 Rg 不报区间，等于隐藏了结论对取点策略的依赖。

## g11 `.dat` 曲线文件

- **作者定义**：「注意：这会将它们保存为 .dat 扩展名。这是 SAXS 散射曲线的标准格式。」
- **=** 1D 曲线的交付格式（交给 ATSAS 等下游）；**≠** 原始数据（原始数据是探测器图像 tif/cbf）。
- **为什么重要**：区分"原始数据"与"交付物"决定要不要保留图像、以及归档该存什么。

## g12 绘图选项卡（Profiles / IFTs / Image / Series）

- **作者定义**：「Profiles选项卡用于查看单个散射曲线。IFTs选项卡用于查看逆傅立叶变换，Image选项卡用于查看探测器图像，Series选项卡用于查看SEC-SAXS 数据。」
- **=** 按**数据形态**分的视图；**≠** 功能菜单；Series 是 SEC-SAXS 专用，不是"多条曲线"。
- **为什么重要**：被问"该在哪里看什么"时，答案是数据形态，不是功能名称。
