## 主窗口：三面板

| 面板 | 位置 | 放什么 |
|---|---|---|
| 信息面板 | 左上 | 当前会话/环境信息 |
| 控制面板 | 左下 | 文件选项卡（浏览目录、文件类型过滤、加载 .cfg）、各分析面板（Guinier 的「控制」「参数」区在这里） |
| 绘图面板 | 右 | 绘图区 + 底部导航/控制栏 |

- 三个面板都可停靠、可拖动：**单击面板标题栏**后拖动，按住时会看到蓝色矩形指示落点。
- 左右区域比例由**分隔条**控制（单击并拖动）；主窗口大小由角/边缘拖动。

## 绘图面板：四个选项卡（按数据形态分）

| 选项卡 | 看什么 | 本仓库哪条 skill 会用到 |
|---|---|---|
| Profiles（主绘图） | 单条/多条散射曲线——**还原流水线与 Guinier 都在这里发生** | `reduce-saxs-frames-to-curves`、`assess-guinier-fit-quality` |
| IFTs | 逆傅立叶变换（距离分布） | 不在覆盖范围（§6 只说"参考在线文档"） |
| Image | 探测器原始图像 | `configure-bioxtas-raw-for-a-dataset`（看原始帧/掩膜效果） |
| Series | SEC-SAXS 数据 | **不在覆盖范围**（明列为边界） |

选项卡顺序可单击拖动调整；每个选项卡底部有导航/控制栏，多数按钮各自独立，但**共享**一套导航按钮。

## 顶部菜单栏

| 菜单 | 关键项 |
|---|---|
| Files | **Loading Settings**（从 .cfg 加载设置；也可双击控制面板文件选项卡里的 .cfg）、**Save Settings**（把全部设置含图像校准与图像蒙版存成 .cfg） |
| Options | —（与"视图/工具"重复的通路之一） |
| View / Tools | 只是访问别处选项的另一种方式，没有独有项 |
| Help | 有其它通路到不了的项目 |

> 注意：真正改变分析结论的是 Files 菜单里的两项——**加载**与**保存设置**。这也是为什么"配置"值得一条独立 skill。

## 文件选项卡（控制面板左下）的操作要点

1. 文件夹按钮 → 定位到目标目录 → Open，目录内容显示在 RAW 的文件浏览器里。
2. 文件列表内可导航：向上箭头对应文件名 `..`，双击目录进入。
3. 底部下拉菜单设**文件类型过滤器**（BL19U2 数据选 `TIF 文件 (*.tif)`）。
4. 多选：`Ctrl` + 单击逐个选；单击一个再 `Shift` + 单击另一个选区间。

## Profiles 列表的状态语义（本仓库最常引用的机检信号）

| 信号 | 含义 | 出处 |
|---|---|---|
| 文件名背景变**蓝** | 已被选中（成为 Subtract / 分析的操作对象） | §4 第⑥步 |
| `A_` 前缀 + **绿色** | 平均散射曲线 | §4 第⑦步 |
| `S_` 前缀 + **红色** | 扣减（净散射）曲线 | §4 第⑨步 |
| 文件名前的 `*` | **有未保存改动**；`*` 消失才代表已写盘 | §4 第⑩步 |
| 文件名左侧的**眼睛**图标 | 切换该曲线的显示/隐藏（有斜线=隐藏） | §4 第⑧步 |
| **星标** | 标记"我是背景"（Subtract 时被减去的对象） | §4 第⑨步 |

判断"能不能安全删掉列表里的文件"的唯一信号：**`*` 是否已消失**。
