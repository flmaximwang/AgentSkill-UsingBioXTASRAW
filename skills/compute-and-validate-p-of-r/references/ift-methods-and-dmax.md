## 1. 为什么不能直接傅里叶变换

P(r) 的定义对 I(q) 是一个 0→∞ 的积分：

```
P(r) = (r²/2π²) ∫₀^∞ q²I(q)·sin(qr)/(qr) dq
```

实战数据没有无穷 q 范围，还有噪声。**直接变换会把截断伪影塞进 P(r)**。IFT 反过来做：

```
I(q) = 4π ∫₀^{Dmax} P(r)·sin(qr)/(qr) dr
```

即"造 P(r) → 正变换 → 与实测 I(q) 比"。拟合标准 = 实际拟合优度 χ² **+** 正则化项（P(r) 平滑度、正性、α 权重变化下解是否剧变）。

要一起定三件事，**互相耦合**：① Dmax（积分上限）；② α（χ² 与正则化项的权重）；③ 给定 Dmax、α 下最优的 P(r)。

## 2. 三法对照表

| 维度 | GNOM | DIFT | BIFT |
|---|---|---|---|
| 来源 | ATSAS 包（需单独安装；RAW 提供接口） | DENSS 内建（纯 Python；算法同 `denss.fit_data.py`，不需装 DENSS） | RAW 原生 Bayesian |
| Dmax | 手动；`Auto Dmax` 自动给起点 | 自动或手动；`Auto Dmax` 给起点 | **完全自动** |
| α（平滑参数） | 手动 / 自动 | 自动扫 α，取"能给出好拟合的最高 α"；`Scan Alpha` 扫 **40 个数量级**；界面用 log10(α) | **完全自动** |
| 端点约束 | 可开关 `Force to 0 at Dmax`（默认 Y，即强制 P(Dmax)=0） | **不能**选/取消强制 P(r=0)、P(r=Dmax) 为零（数学上已限制为零） | 自带 |
| 质量指标 | `Total Estimate`（0–1，1 理想，至少 "REASONABLE"） | **无** "Total Estimate" | 无 |
| 解的唯一性 | 一般 | 一般 | **唯一解**（"only have one possible solution"） |
| α/Dmax 联动 | — | 改 Dmax 后再 `Scan Alpha` 可能得到不同 α；`Auto Dmax` 不受 α 影响 | — |
| 改 q 范围后 | 需重设 | 需重按 `Scan Alpha` | **必须重按 `Run`**（BIFT 慢） |
| 输出格式 | **`.out`**（GNOM 格式全文） | **`.ift`**（与 BIFT 同格式） | **`.ift`** |
| 下游兼容 | 所有需 GNOM `.out` 的程序：**DAMMIF/N、AMBIMETER、ATSAS 链** | **DENSS** 电子密度；不产出 GNOM `.out` | **DENSS**；**不兼容 DAMMIF/其它 ATSAS** |

**选法判据（唯一有效的一问）**：下游要用哪个重建程序？

- DAMMIF / DAMMIN / AMBIMETER / 任何 ATSAS 链 → **GNOM**，出 `.out`。
- DENSS 电子密度重建 → **BIFT 或 DIFT**，出 `.ift`（两者格式相同）；BIFT 更省事（全自动、唯一解）但你不控制 Dmax。

同一份好数据三法给的 Dmax 应有差异但互相吻合（官方 GI 实例：GNOM 102 / BIFT ~100 / DIFT 115，BIFT 与 GNOM 被文档判为 "in good agreement"）。

## 3. Dmax 八步定法

> 骨架：先解除约束、让数据自己说话，再恢复约束。

1. 打开 IFT 界面（默认给 `datgnom` 算出的合理 Dmax）。
2. 起始 q 对齐 Guinier 拟合（新版本 RAW 自动；旧版本手动）。
3. **把 Dmax 设成初始值的 2–3 倍**。
4. 看 P(r) 在哪里**自然落到 0**，把 Dmax 设到该点。
5. **关闭 force-to-zero**。
6. 在关约束下上下微调 Dmax，直到 P(r) 自然趋零。
7. **重新打开 force-to-zero**。
8. 若给 DAMMIF/N 用，截断 q（见第 5 节）；截断后可能需再微调 Dmax。

**辅助技巧**：增大 Dmax 会同时增大 P(r) 的 Rg 与 I(0)，可据此判断方向；残差系统性偏差大时把 **α 设为自动值的一半**再调（GNOM/DIFT 适用）。

**不确定度**：Dmax **绝不可能优于 5%**，有时接近 **10%**；柔性体系更差。官方 GI 实例合理区间约 **99–104**（5% 变化）。

## 4. P(r) 判据

**硬判据**

1. **Dmax 处平滑渐降为零**（最重要、最主观）。大分子边界不锐利 → 应"渐降"而非"被截断"。**陡降 = Dmax 低估；绕零振荡 = 高估；平滑趋零 = 合适。**
2. **正变换回 I(q) 能拟合实测曲线**：χ² ≈ 1；归一化残差平坦、随机分布于零附近。
3. **P(0)=P(Dmax)=0**：r=0 无电子对；超过最大尺寸无电子对。通常由 IFT 内部约束强制。

**常用判据**

4. **Guinier 与 P(r) 的 Rg、I(0) 吻合**（刚性体系）。柔性/无序体系：P(r) 的 Rg、I(0) 特征性地更大且更可靠。
5. **P(r) 恒正**。**例外**：膜蛋白被脂/去污剂包封（如 lipid nanodisc）时脂/去污剂电子密度低于缓冲液 → 特征性**负 dip**。

判据不满足通常意味着数据有**聚集或粒子间干涉**，不应继续分析。

## 5. 截断规则与"给谁用"

| 下游 | 是否截断 | 规则 |
|---|---|---|
| **DAMMIF/N**（珠模型） | **要** | 截断到 **max q = 8/Rg 或 0.25–0.30 1/Å，取较小者**；截断后可能需再微调 Dmax。原因：DAMMIF 不建模水化层与内部结构，高 q 引入误差。 |
| **DENSS**（电子密度） | **不要** | 用**全 q 范围**。用全 q 的 `.ift` 或 `_full.out`，别用被截断的 `.out`。 |

官方 GI 实例：GNOM 勾 "Truncate for DAMMIF/N" 后 q_max **由 0.283 降到 0.238**（取 8/Rg 或 0.30 中较小者）。

## 6. 坏 P(r) 的两类病理

**症状定义**（"坏"=两件事之一）：① 一直找不到好 Dmax（怎么增大都不平滑趋零）；② 增大 Dmax 时 P(r) 变负。

**诊断动作**：把 Dmax **延伸远超你以为正确的值**，看末端落哪一档。

| 末端行为 | 判定 | 对 Rg/I(0) 的影响 |
|---|---|---|
| 小振荡、贴近零 | **好** | 正常 |
| 持续为负 | **排斥性粒子间干涉** | Dmax 被压小 → Rg/I(0) **偏低** |
| 保持略正、显著长尾 | **聚集** | Rg/I(0) **偏大** |

**交叉验证（必须做）**：**少量聚集在 P(r) 上像柔性体系**。用 **Guinier**（残差 smile→聚集、frown→排斥）与 **Kratky**（是否有高 q 平台→柔性）判真实状态；二者都指向坏 buffer 扣减时先修缓冲液匹配。

---

## 7. 报告清单（照抄）

报一个 P(r) 必须带：**IFT 方法（GNOM/DIFT/BIFT）+ Dmax ±不确定度（≥5%，有时 ~10%）+ χ² + Guinier 与 P(r) 的 Rg/I(0) 一致性 + q 区间 + 是否截断（给谁用）**。缺任一项，别人无法复现或判断你的 Dmax 是否可信。
